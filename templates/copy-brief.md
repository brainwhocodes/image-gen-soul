# Copy brief

Record the reader, purpose and tone using the current brief. Reuse settled answers.

| Decision | Record for this job |
|---|---|
| Surface | Marketing page, product page, component, guide or export |
| Reader and task | Who is reading and what they need to do |
| Supported offer | Features and outcomes confirmed by the source or working product |
| Evidence | Supplied facts, demonstrations and sources; identify missing support |
| Voice | Supplied samples or an explicitly proposed register based on the brief |
| Main action | Label, destination and actual result |
| Protected material | Names, figures, qualifications, links, code and generation records |
| Required states | Initial, empty, loading, validation, error, success as applicable |
| Edit scope | Copy only, content restructure or a visual change requiring new mockups |

For each page, write its main claim and next action. Name the specific detail each section adds. Record lint findings with file, quoted span, disposition and reason; never use a whole-file exception to hide unreviewed copy.

Before delivery, compare the revised copy to the protected material and follow the main action in the browser. Save the final text with the page source and refresh any affected preview or downloadable archive.
